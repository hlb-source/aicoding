## 4. 实现流程

**方案：分段录音识别**

```
循环执行：
  1. ffmpeg录制5秒音频 → temp.wav
  2. Whisper加载base模型（首次10-20秒）
  3. transcribe()识别 → text
  4. 输出到屏幕和logs/voice.log
  5. 删除temp.wav
  6. 等待1秒后重复
```

**性能：**
- 总延迟：7-10秒（录音+识别）
- 内存：~500 MB
- CPU：30-50%（识别时）

### 7.7 Python调用实现

**调用方式：**
```python
import subprocess

# 语音识别文本
text = "创建文件 main.py"

# 检测是否为命令（关键词匹配）
keywords = ['创建', '读取', '编辑', '删除', '运行', '写代码', '搜索']
is_command = any(text.startswith(kw) for kw in keywords)

if is_command:
    # 直接执行opencode
    result = subprocess.run(
        ['opencode', 'run', text],
        capture_output=True,
        text=True,
        timeout=60
    )
    
    # 显示执行结果
    print(f"[执行] {text}")
    print(result.stdout)
    
    # 记录日志
    with open('logs/commands.log', 'a') as f:
        f.write(f"{datetime.now()} | 执行: {text}\n")
        f.write(f"结果: {result.stdout}\n")
```
